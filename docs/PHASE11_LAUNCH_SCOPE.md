## Shared integration requirements

Use the existing native API client/session. Read [FRONTEND_INTEGRATION_GUIDE.md](FRONTEND_INTEGRATION_GUIDE.md), permission matrix and individual feature contracts before field mapping. Owner A–D routes require owner/admin role **and actual current ownership**. Admin analytics/resources can oversee other cafes; admin account-management protections remain Super Admin-specific. Unknown fields are rejected, writes are same-origin JSON, private responses no-store, images reauthorize even on ETag 304. In-flight authority changes can return the documented 409 conflict; refresh auth/entity before retry.

Mutations need feature-specific ambiguity handling: stock repeats the same body/key, menu edits refetch versions, CSV repeats identical confirmation, review creation recovers via own-review GET. Never blindly regenerate a stock key, convert null to zero, render stored text as HTML or merge owner-only fields into public caches. New X-Request-ID can be shown/copied for support without including request bodies/cookies; it is not a credential or trusted incoming trace identifier.

## Required launch acceptance

Frontend role owners must record evidence for guest/customer/owner A/owner B/admin/disabled sessions, cross-origin denial, tenant switch/revocation, ambiguous network retry, version race, private-media 304 denial, quantity removal, source/null/cohort rendering, marketing preference consent and inbox isolation. Exercise Node scoped SSE and Cloudflare room/reconnect snapshot recovery separately. Verify no ls_customer/mock identity or data becomes authoritative in HTTP mode.

Current browser/E2E suites prove preserved existing UI and sensor journeys, **not integration of the still-mock customer adapter**. A full A–H product launch needs explicit role journeys on the integrated frontend and documented handling of unsupported visible prototypes. Responsible roles: frontend owner implements; product/release owner accepts scope; backend owner validates contracts/security. These manual integration decisions remain blockers and were not silently waived.
